# 🌌 Boykisser OS v1.0 (Arch Linux + i3wm Layout) 🦊

Добро пожаловать в репозиторий конфигурационных файлов для ультимативного неонового Vaporwave-сетапа, собранного на базе **Arch Linux** и оконного менеджера **i3wm**.

## 🎨 Визуальный стиль и Окружение
* **Цветовая палитра:** Розово-фиолетовый неон / Нуар / Vaporwave
* **Оконный менеджер:** `i3wm` (с кастомными зазорами Gaps и скрытыми синими заголовками окон)
* **Эмулятор терминала:** `kitty` (с полупрозрачностью и размытием фона)
* **Нижняя панель / Док:** `Polybar` (парящий неоновый дизайн со скруглёнными углами)
* **Верхняя панель:** `i3bar` + `i3status` (лаконичный мониторинг звука, батареи и времени)
* **Меню запуска:** `Rofi` (полупрозрачное неоновое окно приложений на `Mod + D`)

## 🛠️ Спецификации кастомизации

### 🤖 Terminal Welcome (Fastfetch)
При старте терминала `kitty` вылетает кастомное хакерское приветствие с детализированным Braille-артом **Бойкиссера** и перекрашенной в фиолетовый неон палитрой.

### 📝 Текстовый редактор (Nano)
Полностью пересобран под IDE: включена мышка, добавлены сочные бирюзовые номера строк, включена подсветка синтаксиса для всех конфигов и языков, а хоткеи перевешены на человеческие (`Ctrl+C`, `Ctrl+V`, `Ctrl+S`, `Ctrl+Q`).

### 🌐 Браузер (Firefox)
Ультра-минималистичная тема в одну строчку (вкладки и адресная строка делят одну панель). Страница `about:newtab` полностью очищена от мусора, перекрашена в тёмный цвет, а строка поиска подсвечивается неоново-розовым цветом в тон румянцу котика.

### ⚙️ Системные фиксы
* **Звук и Яркость:** Стабильное управление через клавиши `Fn` с помощью `pactl` и `brightnessctl`.
* **Автоматика:** Ноут сладко спит при закрытии крышки и требует пароль через размытый `betterlockscreen` при открытии.
* **Скриншоты:** По кнопке `PrtSc` утилита `scrot` отправляет снимки выделенной области в кастомную папку `~/Pictures/Screenshots/`.
* **Автомонтирование:** Флешки exFAT и внешние жёсткие диски монтируются автоматически без вылетания ошибок авторизации.

## 🚀 Как развернуть этот сетап с нуля?

1. Установите утилиту **GNU Stow**:
   ```bash
   sudo pacman -S stow
   ```
2. Склонируйте этот репозиторий в домашнюю папку:
   ```bash
   git clone https://github.com/MMRTrip/dotfiles ~/dotfiles
   ```
3. Зайдите в папку и примените симлинки для нужных модулей:
   ```bash
   cd ~/dotfiles
   stow i3 kitty polybar fastfetch nano bash i3status picom
   ```
